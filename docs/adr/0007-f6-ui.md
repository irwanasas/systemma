# 0007 — F6 UI decisions

Status: accepted

## Decisions

- Palette Warm Atelier and font Inter were chosen by the owner. Inter is self-hosted with `@fontsource-variable/inter` so builds do not depend on Google Fonts.
- Derived tokens (checked for WCAG AA): surface `#FBF9F6`, muted surface `#EDE8E1`, divider `#D9D1C6`, input border `#8C8177` (3.6:1), muted text `#5F574F` (6.3:1), strong primary `#9C4630` for text links, and status colors success `#2E6A4B`, warning `#8A5400`, danger `#A1262B`, info `#2D5B7A`, each with a soft background. No dark mode (not required).
- Type scale 1.2 on a 16px base; spacing on Tailwind's 4px base. Admin pages set `data-density="compact"` (36px rows and controls); agent pages keep 44px.
- Base HTML elements (inputs, selects, tables, fieldsets, alerts, statuses, plain buttons) are styled once in `globals.css`, so server-rendered pages share the system without per-page classes. shadcn `button`, `dialog` and `accordion` are used where behaviour is needed; their `cn` import points to `lib/utils` and their icons are phosphor (lucide and the `cn` package were removed).
- Status is never color-only: order and payment statuses are badges with an icon and a label; amounts carry a sign, icon and label in the payment history; unavailable cart lines have an icon and text.
- The order grid keeps quantities in a per-grid Zustand store, submits hidden inputs to the existing `saveGrid` action, supports arrow keys, and becomes one accordion per color with −/+ steppers below the `md` breakpoint. Its footer DP preview uses `dpAmountFor`, the same integer formula as SQL `dp_amount_for`; the cart and orders use the SQL value.
- Custom size lives in a disclosure under the grid with inline validation against the configured limits.
- Checkout uses a dialog with the R-06 text, DP amount, deadline and a required confirmation checkbox. The DP deadline has a live countdown; bank account numbers have a copy button; the invoice has a print button and print styles.
- The DP review queue is two columns on large screens: list left, large proof right.
- `prefers-reduced-motion` disables animations and transitions globally.
- `@next/next/no-img-element` is off because proofs are shown from 5-minute signed URLs that `next/image` should not cache.
